# Time Travel Agency

## Description
Cette application web permet d’explorer des destinations de voyage dans le temps comme Paris 1889, le Crétacé et Florence 1504.

## Fonctionnalités
- Exploration de destinations temporelles
- Interface immersive
- Chatbot interactif
- Réservation simulée

## Technologies utilisées
- React
- Vite
- Tailwind CSS
- Lovable
